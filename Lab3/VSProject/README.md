# ЛР3 — готовый проект для сборки «одной кнопкой» в Visual Studio 2019

Этот каталог — полноценный, уже настроенный проект Visual Studio: открываете `.sln`,
жмёте **Build**, никаких дополнительных скриптов не нужно.

За основу взят официальный пример Intel SGX SDK `SampleEnclave` (методичка прямо
указывает: «данная лабораторная воспроизводит пример от Intel»), поэтому в проекте
остались демонстрационные файлы Intel (`Enclave\Edger8rSyntax\`,
`Enclave\TrustedLibrary\`, `App\Edger8rSyntax\`, `App\TrustedLibrary\`) — они не мешают
и не используются нашим кодом, просто входят в состав `.edl`/`.vcxproj`, чтобы проект
собирался без правок конфигурации.

**Наш код** (то, что реально отвечает на вопросы задания):
- `Enclave\Enclave.cpp`, `Enclave\Enclave.edl` — защищённая таблица учётных данных и
  ECALL-функции `ecall_get_count`, `ecall_get_record`, `ecall_add_record`.
- `App\App.cpp` — клиентское приложение: создаёт анклав, по командам пользователя
  запрашивает записи по индексу или добавляет новую, выгружает анклав при выходе.

## Как собрать

**Предварительно нужны:** Visual Studio 2019 + Intel SGX SDK (NuGet-пакет или
классический установщик — см. `Lab3/README.md` в корне лабораторной).

1. Откройте `SampleEnclave.sln` в Visual Studio 2019.
2. Если SDK подключён через NuGet (а не через системную переменную окружения),
   задайте путь к SDK один раз (PowerShell, перед открытием VS, либо через
   **Project → Properties → VC++ Directories**, если SDK лежит не в стандартном месте):
   ```powershell
   $env:SGXSDKInstallPath = "C:\путь\к\распакованному\Intel.SGX.SDK\build\native\"
   ```
3. Вверху выберите конфигурацию **Simulation** и платформу **x64**.
4. **Build → Build Solution** (Ctrl+Shift+B).

Результат: `x64\Simulation\App.exe` и `x64\Simulation\Enclave.signed.dll`.

> При первой сборке автоматически сгенерируется тестовый ключ подписи анклава
> (`Enclave_private.pem`) — это ожидаемо, он не нужен в репозитории (в `.gitignore`).

## Запуск

Симуляционные библиотеки SGX (`sgx_urts_simd.dll` и т.п.) нужно скопировать рядом
с `App.exe` из SDK (`...\bin\x64\Release\*sim*.dll`) — без них `.exe` не найдёт
зависимости. Либо просто запустите `App.exe` из каталога, куда их уже положили.

Команды внутри программы:
```
cmd> 0              — получить запись по индексу
cmd> add текст       — добавить новую запись, вернёт её индекс
cmd> 5               — забрать добавленную запись обратно
cmd> -1              — выход
```
